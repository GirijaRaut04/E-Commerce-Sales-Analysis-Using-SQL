Project Title: E-Commerce Sales Analysis Using SQL

Dataset: E-Commerce Sales Dataset (Kaggle)

Problem Statement:
Analyze e-commerce sales data to understand revenue trends, customer behavior, and product performance using SQL queries.

Tasks Performed:
Data extraction using SQL joins across multiple tables
Revenue and sales aggregation using GROUP BY and SUM
Monthly sales trend analysis using date functions
Identification of top-selling products and high-value customers
Detection of low-performing products and categories

Skills and Tools Used:
SQL
Joins and Subqueries
Aggregate Functions
Date Functions
Business Analytics

Real-World Application:
Sales performance monitoring, customer segmentation, and business decision support
